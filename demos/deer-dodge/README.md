# 小鹿闪闪

手机和电脑都能玩的八关森林躲避游戏。操纵小鹿收集每关的三颗星星，躲开移动的木桩与蜜蜂，然后进入彩虹门。过关时小鹿会跳起来转圈。

## 操作

- 电脑：方向键或 WASD 移动，空格暂停。
- 手机：按画面下方的方向键，或在游戏画面上拖动来移动小鹿。
- 点击右上角喇叭按钮可开启或关闭音效；设置会在本机保存。

直接打开 `index.html` 即可游玩；也可以从仓库首页进入。游戏不依赖外部资源或构建步骤。

离线 iPhone App 项目见 [`ios/DeerDodge/`](../../ios/DeerDodge/)。

## iPhone 主屏幕版本

在 Safari 打开线上游戏，点“分享”→“添加到主屏幕”，并选择“作为网页 App 打开”。首次联网打开后，游戏资源会缓存在设备上，可离线游玩。无需 Xcode 或开发团队。
