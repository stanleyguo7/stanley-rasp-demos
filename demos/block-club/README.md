# 方块俱乐部 · 俄罗斯方块

纯 HTML、CSS 和 JavaScript 游戏，无需安装依赖或构建。

## 运行

在仓库根目录执行 `python3 -m http.server 8080`，访问
`http://localhost:8080/demos/block-club/`；也可直接打开此目录的 `index.html`。

## 功能与操作

- 方向键 ← → 移动、↑ 旋转、↓ 加速，空格直接落下，P 暂停或继续。
- 手机端提供触控按钮。
- 消行计分、每消除 10 行升级、下一个方块和落点预览。
- 最高分保存在当前浏览器本地。
- 点击“AI 自动玩”即可开始自动操作，关闭后可手动接管；支持暂停和重新开始。
- 切换到后台时自动暂停。

AI 搜索合法移动路径，评估消行、堆叠高度、空洞和表面起伏，并对最好的 8 个候选继续考虑下一个方块。AI 模式使用独立的逐步操作节奏，手动模式使用随等级加快的重力。

## 验证

需要 Node.js，在仓库根目录运行：

```sh
node demos/block-club/tests/ai.cjs
```

测试覆盖连续自动游玩、消行、合法位置、暂停、手动接管、重新开始和指定局面的双行消除。

字体通过 Google Fonts 加载；无法联网时使用系统字体，游戏逻辑可离线运行。
